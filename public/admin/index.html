Keep catalogs in sync

Always delete from this Mac admin (Library → Delete series / Delete movie). That removes Mac + R2 + the phone catalog (GCE) together.

If you delete on GCE instead, open Library here — refresh syncs from the phone catalog and drops local titles that were published but no longer exist online. Local-only encodes (never uploaded) stay.

If the phone still shows something missing on Mac, use Clean leftover phone titles.

Disk cleanup

Clears leftover uploads on this machine (temp files / failed encodes). Does not delete the database or R2. On GCE after accidental GB uploads, use Purge all local packages.
